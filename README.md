# СТТ-Сервис — аренда спецтехники

Сайт в фирменном образе STT-SERVIS: оригинальный аватар из Telegram, графит, стальные оттенки, золотисто-оранжевые акценты, спокойная типографика и фотографии из открытого каталога компании. Без внешних JavaScript-зависимостей.

## Локальный запуск

```powershell
node prepare.mjs
node server.mjs
```

Адрес: http://127.0.0.1:4197/. Дополнительный аргумент сервера меняет порт.

## Структура

- `dist/index.html`: оболочка страницы.
- `dist/styles.css`: общие компоненты и адаптивность.
- `dist/brand.css`: фирменное оформление, страницы и мобильная версия.
- `dist/brand-home.js`: главная, направления услуг, фотографии и быстрый подбор.
- `dist/app.js`: данные каталога, страницы и взаимодействия.
- `dist/assets`: локальные изображения, шрифты и знак.
- `prepare.mjs`: создаёт адресуемые страницы для статического хостинга.
- `.github/workflows/pages.yml`: сборка и публикация в GitHub Pages.
- `build-pages.mjs`: подготовка файлов с префиксом репозитория.
- `ASSET-SOURCES.md`: источники и пояснения к изображениям.

## Реализовано

Главная, каталог восьми вариантов, фильтры, сортировка, сравнение до трёх машин, карточки техники, галереи, выбор оборудования, шесть страниц работ, четыре сервисных направления, компания, условия, фотографии рабочих процессов, контакты, три полезных материала и пояснение обработки данных. Подбор по шагам сохраняет введённые данные при возврате и подготавливает запрос.

## Обращения

Сайт подготавливает текст запроса. Пользователь проверяет его, копирует и отправляет в Telegram либо открывает письмо в своей почтовой программе. Автоматическая отправка обращений, CRM и загрузка файлов на сервер не подключены. Фотографии объекта можно приложить в переписке. Сайт не показывает ложного подтверждения отправки.

## Данные компании

Контакты, категории, справочные параметры и тарифы взяты из опубликованных материалов stt-servis.ru. Фото иллюстрируют категории; они не доказывают владение конкретными машинами или выполнение конкретных проектов. Перед использованием как официального коммерческого сайта компания должна подтвердить актуальные цены, парк, условия аренды, состав услуг и реквизиты. Вымышленные отзывы, результаты объектов и сотрудники не добавлялись.

## Проверки

Проверены синтаксис JavaScript, локальная выдача страниц, загрузка изображений и шрифтов. В браузере проверены фильтр узкого проезда, добавление и таблица сравнения двух машин, подготовка запроса из сравнения, мобильная главная и меню при ширине 390 px. Внешние сообщения при проверках не отправлялись.

Запуск структурных проверок: `node checks.mjs`.

## GitHub Pages

Публикация производится только через GitHub Pages. Workflow запускается при push в `main` либо вручную. В Settings → Pages должен быть выбран Source: GitHub Actions.

Для проверки проектного адреса локально:

```powershell
node prepare.mjs
node build-pages.mjs --base /stt-servis
node server.mjs 4198 pages /stt-servis
```

Адрес проверки: http://127.0.0.1:4198/stt-servis/. Workflow получает реальный `base_path` из `actions/configure-pages`, поэтому поддерживает и проектный адрес, и корень пользовательского домена. Сборка выполняется в `pages/`, этот каталог не коммитится.
